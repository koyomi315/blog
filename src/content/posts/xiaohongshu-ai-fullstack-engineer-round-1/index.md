## 二、Agent 评测平台

3. 介绍评测平台的主要流程，线上评测与离线评测有什么区别？
   - 当时回答：线上评测直接使用业务 Agent 的历史 Trace，按配置的代码评分器或大模型评分器打分，不涉及重放。离线评测以测试集为输入重新运行 Agent，对新产生的 Trace 评分，用于观察升级后的能力回归和 Bad Case 改进情况。
   - 追问：测试集由谁构建，标注人员如何参与评测与改进？
     - 当时回答：区分业务 Agent 开发、评测平台开发和平台使用人员；标注人员依据专家判断评估表现并构建测试集，为后续改进提供素材。
   - 追问：业务 Agent 的 Trace 如何采集、同步到评测平台并保存？
     - 当时回答：业务侧接入 Langfuse 保存 Trace，评测平台再同步到自己的数据库。我的理解是保存三层信息：用于页面展示的基础信息、按平台字段映射的数据，以及原始 Payload。
   - 追问：Scorer 如何设计，有没有按业务定制？
     - 当时回答：认为当时基本沿用 Langfuse 的评分器思路，功能与设计大致一致，还没有结合业务需求作进一步改进。

## 三、异步任务、幂等与故障恢复

4. 自动定时评测有哪些阶段，为什么采用异步任务？
   - 当时回答：周期性触发收集 Trace 并构建测试集、执行评分、归集低分 Bad Case 三个阶段。任务触发后不一直阻塞等待，通过消息队列推进各阶段和状态流转。
   - 追问：重复扫描时，怎样避免同一任务、同一时点创建多个执行？
     - 当时回答：外部周期调度触发扫描接口；重复触发，或上一轮扫描未完成下一轮又开始，都可能重复创建执行，因此需要幂等控制。
   - 追问：重复投递导致多个 Worker 领取同一任务时，如何控制并发？
     - 当时回答：提到 CAS 和 Revision。Worker 领取前比较任务是否处于预期状态，符合才修改字段并领取，否则不领取；没有展开 Revision 的具体实现。
   - 追问：如果 Worker 全部中断或重启，任务怎样恢复？已经完成的部分会不会重做？
     - 当时回答：定时扫描长时间未推进的任务并重新投递，恢复后由 Worker 继续领取。各阶段按条处理数据，并做幂等控制，例如前一个 Worker 已完成前五条，后续重试不应重复处理这些数据。
5. 继续追问：CAS 具体比较、修改什么状态？
   - 当时回答：以“未处理”变为“正在处理中”为例，比较预期状态后修改对应字段。
6. 幂等业务键如何构建？多次创建时，怎样保证同一业务使用一致、唯一的键？
   - 当时回答：印象中既有哈希生成 ID，也有组合任务 ID、Case、执行时间等业务字段的方式。
   - 追问：如何保证重复创建时业务键的一致性和唯一性？
     - 当时回答：记得做过相应限制，确保同一任务生成对应的唯一业务键，但具体细节当时记不清楚。

## 四、Tool Mock

7. Tool Mock 如何拦截工具调用，业务 Agent 怎样接入？
   - 当时回答：需要业务 Agent 开发配合接入评测 SDK，通过路由配置区分真实业务调用与评测调用；后者转发到 Tool Mock 平台。
   - 追问：转发后怎样选择调用模式，并匹配 Fixture？
     - 当时回答：可以调用真实工具、使用平台通用 Mock，或调用业务方自己提供的 Mock。通用 Mock 的匹配印象中涉及 Agent、测试集、Case、工具和入参五类信息，再返回预置结果。

## 五、OnCall Agent 与 RAG

8. 介绍个人 OnCall Agent 项目的组成和技术选型。
   - 当时回答：使用 Spring AI 封装模型交互与工具调用，自己主要做流程编排、提示词与上下文管理；用 Milvus 支持知识库构建和向量检索，配置 Embedding、Chunk 划分与检索参数；另有对话交互前端。
   - 追问：用户提出运维问题后，RAG 问答流程怎样运行？检索不到知识怎么办？
     - 当时回答：先将 Query 向量化，到向量数据库检索语料，再将语料加入上下文让模型生成回答。通过系统提示词约束回答依据召回知识；没有相关知识时，可以追问，或如实说明不知道。

## 六、算法题：连续子数组的最小值之和

9. 给定数组，求所有连续子数组的最小值之和。
   - 回忆中没有额外限制；具体输入输出格式和测试结果未记录。
   - 当时思路：先用两层循环枚举子数组，再遍历求每个子数组的最小值，时间复杂度 O(n³)，额外空间 O(1)。
   - 追问：能否优化至 O(n²)？
     - 一开始类比前缀和，考虑能否加速区间最小值计算；最终在提示下，想到每次外层循环初始化最小值，内层向右扩展子数组时更新最小值并累加到答案，以两层循环完成，优化至 O(n²)。
