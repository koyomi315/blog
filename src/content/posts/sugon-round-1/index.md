## 二、Java 基础与反射

2. Java 中 == 与 equals 有什么区别？
   - 当时回答：== 对基本类型比较值，对引用类型比较地址；自定义对象可以通过实现 equals 比较具体值。没有完整说明 equals 的默认行为。
3. int 与 Integer 有什么区别，包装类有什么作用？
   - 当时回答：Integer 是包装类，提供一些整数相关方法；它可以为 null，在业务中表达特殊语义，而 int 只能保存数值。
4. 什么是反射，有什么用途与优缺点？
   - 当时回答：结合自己对 Spring Boot 的理解，提到依赖注入、降低代码耦合；认为反射能访问原本受限制的私有属性或方法，可能降低安全性。
   - 追问：为什么认为反射会带来安全性或访问权限方面的问题？
     - 当时回答：原本外部无法访问的成员变得可以访问，理解为访问权限有所扩散。

## 三、HashMap 与线程

5. HashMap 的底层结构和 put 流程是什么？
   - 当时回答：数组加链表或红黑树。先计算哈希并定位桶，空桶直接插入；已有元素时比较 key，相同则覆盖值，否则按冲突处理并放入链表等结构。
6. 通用线程状态模型有哪些状态，状态之间如何流转？
   - 当时回答：新建、就绪、运行、阻塞、消亡。就绪线程取得时间片后运行，执行 sleep 或 I/O 等操作可能挂起阻塞，任务结束后终止。
7. 使用线程池应注意哪些问题？
   - 当时回答：倾向自定义线程池并配置参数；认为预定义线程池的无界队列可能导致任务堆积和 OOM，没有进一步区分不同线程池类型。
   - 追问：部分线程或任务发生故障、长期占用资源时，会有什么影响？
     - 当时回答：认为部分线程可能一直被占用、无法回收，导致可用线程减少、任务堆积，业务等待时间变长；当时也不确定是否回答到所问方向。
8. volatile 有什么作用，适合什么场景？
   - 当时回答：用于多个线程读写共享变量时保证可见性，并用“从主内存读取、写回主内存”描述自己的理解；强调不能保证原子性。
   - 当时举例：两个线程可能同时读到相同的 i，分别加一后发生写入覆盖，因此两次 i++ 最终只增加一。

## 五、数据库索引与 Bean 生命周期

10. 数据库索引为什么选择 B+ 树，与哈希、B 树和二叉搜索树相比有什么特点？
    - 当时回答：哈希不便范围查询；B+ 树等多路树层高较低，可以减少磁盘 I/O；B+ 树记录保存在叶子节点，访问记录的时间相对稳定。
11. Spring Bean 的生命周期是什么？
    - 当时回答：认为 Bean 在依赖注入时完成创建，交给框架管理；并将生命周期结束理解为“注入它的程序都执行完后可以回收”。当时没有展开完整的生命周期过程。
